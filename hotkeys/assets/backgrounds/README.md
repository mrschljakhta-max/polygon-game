# Mission board background

Завантажуйте сюди базовий фон дошки:

- `sectors-board.webp`

Фон має бути 16:9 і використовуватись як нерухома основа сцени. Папки, нитки, підсвічування, клавіатурна навігація та анімації накладаються кодом поверх нього.

Якщо фон відсутній, система використовує темний CSS-fallback і не ламається.
