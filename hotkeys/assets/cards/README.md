# Mission board card assets

Завантажуйте сюди 8 окремих зображень папок із прозорим фоном.

Очікувані назви файлів:

- `sector-01.webp`
- `sector-02.webp`
- `sector-03.webp`
- `sector-04.webp`
- `sector-05.webp`
- `sector-06.webp`
- `sector-07.webp`
- `sector-08.webp`

Рекомендації:

- формат: WebP з alpha; PNG теж можна використати, якщо змінити шлях у `mission-board-layout.js`;
- не вшивати картки у Base64;
- зберігати прозорий фон;
- не змінювати HTML/CSS/JS при заміні графіки — достатньо замінити файл з тією ж назвою.

Якщо файл відсутній, меню покаже технічну заглушку і залишиться працездатним.
