# Mission board card assets

Завантажуйте сюди 8 окремих зображень папок із прозорим фоном.

Основні назви файлів:

- `sector-01.webp`
- `sector-02.webp`
- `sector-03.webp`
- `sector-04.webp`
- `sector-05.webp`
- `sector-06.webp`
- `sector-07.webp`
- `sector-08.webp`

Система автоматично спробує PNG, якщо WebP відсутній. Тому можна без змін у коді завантажити:

- `sector-01.png`
- `sector-02.png`
- ...
- `sector-08.png`

Рекомендації:

- найкраще: WebP з alpha;
- PNG теж підтримується автоматично;
- фон карток має бути прозорим;
- не вшивати графіку у Base64;
- при заміні графіки HTML/CSS/JS чіпати не потрібно.

Якщо обидва файли відсутні, меню покаже технічну заглушку `IMAGE MISSING` і залишиться працездатним.
